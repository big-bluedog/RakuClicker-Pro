
# RakuClicker Pro

A lightweight auto clicker for Windows 10/11 (64-bit).

## Features
- Auto Clicker with adjustable CPS
- Multi-Point clicking
- Macro recording and playback
- Smart Delay
- Save and load profiles
- F6 Start/Stop and F8 Emergency Stop

## Download
Download the latest Windows ZIP from the Releases section.

## Installation
1. Download the ZIP file.
2. Extract the archive.
3. Run `RakuClicker Pro.exe`.

No Python installation required.

## Compatibility
- Windows 10 x64: tested
- Windows 11 x64: expected to work, not yet tested
